# DigitLab — live interactive handwritten-digit demo

**Live app:** https://digitlab-handwritten-digit-recognition-6h1q9k.v2.appdeploy.ai/

## What it does

- Draw a digit 0–9 on desktop or mobile.
- Use verified held-out test samples 5, 2 or 0.
- Convert freehand input to 8×8 grayscale pixels.
- Call `POST /api/predict` to run an **actual fully connected neural network** (64 → 64 → 32 → 10).
- Display the predicted digit and softmax probabilities for the five highest-scoring classes.
- Clear the canvas and try again.

The backend loads the [exported model weights](../model-web.json) from this public repository, generated by [export_model.py](../export_model.py) after PyTorch training. Inference uses ordinary matrix multiplication, biases, ReLU activations and softmax — there is no mock result, lookup table or external generative model.

## Source

- `src/main.ts`: canvas interaction, image preprocessing, prediction requests, results view.
- `src/styles.css`: responsive desktop and mobile design.
- `backend/index.ts`: validation, trained model loading and deterministic inference.
- `index.html`: document shell.

The website is deployed with AppDeploy; `@appdeploy/client` and `@appdeploy/sdk` are provided by that platform. These files are mirrored here for source transparency and maintained in the deployed AppDeploy project.

## Accuracy

Training/test setup: scikit-learn Digits dataset, 1,437 train images and 360 held-out test images. The saved model reached **96.94% held-out dataset accuracy**. The same metric **does not apply** to arbitrary browser drawings. Due to differences between training images and drawn strokes, the freehand mode is experimental and can make mistakes.

## Freehand input improvement (GitHub Pages version)

The static site at `docs/` now processes each freehand drawing at **three slightly different centered crop scales** (10%, 16%, 22% margin) and averages the resulting **real neural-network softmax probabilities** before displaying a class. This reduces sensitivity to how tightly the digit was drawn. Verified held-out sample buttons remain single-pass predictions. This is a robustness experiment, **not a claimed or validated accuracy increase on arbitrary handwriting**; further testing and a larger handwriting dataset are still warranted.
