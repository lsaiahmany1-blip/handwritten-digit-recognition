# Handwritten Digit Recognition — Deep Learning with PyTorch

An introductory **AI / Deep Learning** portfolio project developed using Python, PyTorch and scikit-learn. A small neural network classifies grayscale handwritten digits **0–9**.

**Project status:** Model training and command-line predictions were successfully run on a Windows computer. A browser-based interactive demo is planned as the next step.

## 🌐 Live interactive demo

**[Try the live digit recognizer →](https://digitlab-handwritten-digit-recognition-6h1q9k.v2.appdeploy.ai/)**

Draw a digit 0–9 with a mouse or finger (experimental freehand input), or click one of the **verified held-out examples** (5, 2, or 0). The web app calls a backend that executes **the actual 64→64→32→10 PyTorch network weights exported from this repository**, shows its predicted class and top probability scores, and labels the held-out test accuracy separately from freehand accuracy.

[View the website and inference source](web-demo/) · [Exported model weights](model-web.json) · [Weight export script](export_model.py)

**Important:** Freehand drawings can be less accurate than the held-out 8×8 Digits dataset images due to differences in input distribution. This is a learning demo, not production OCR.

## Verified training result

| Metric | Result |
|---|---:|
| Dataset | scikit-learn Digits (1,797 images, 8 × 8 pixels) |
| Training images | 1,437 |
| Held-out test images | 360 |
| Training epochs | 30 |
| Test accuracy | **96.94% (349 / 360)** |
| Neural network | 64 → 64 → 32 → 10 |

The author ran the project locally and checked predictions on test indices **0, 1, 10, and 50**, all of which matched their labels. These four checks are illustrative, **not** the basis of the reported 96.94% accuracy, which comes from the full 360-image test set.

## How it works

1. Load the built-in **Digits** dataset from scikit-learn.
2. Scale pixel intensities from 0–16 into 0–1.
3. Make a reproducible, stratified 80/20 train/test split.
4. Train a fully connected PyTorch neural network with two hidden layers, ReLU, cross-entropy loss and the Adam optimizer.
5. Evaluate accuracy once against the separate test split, then save weights and prediction examples.

## Run locally (Windows PowerShell)

Install **Python 3.10+** and open PowerShell inside the project folder:

```powershell
py -m pip install -r requirements.txt
py train.py
py predict.py --index 0
py predict.py --index 1
py predict.py --index 10
py predict.py --index 50
```

On macOS/Linux, use `python3` instead of `py`.

Running `train.py` generates the artifacts below **locally**:

- `digits_model.pth` — PyTorch model weights
- `results.json` — measured metrics
- `sample_predictions.png` — a grid of actual and predicted digits

**Note:** Binary output files are generated by training and are not currently included in this repository. The JSON file contains the verified metrics from the reproducible local run.

## Limitations

The dataset contains small, cropped, clean 8×8 grayscale digits. **96.94% is not a claim of real-world handwriting recognition accuracy**; camera photos, drawings from a web canvas and unfamiliar handwriting styles may perform very differently. Additional data preparation and evaluation are needed for a production system.
